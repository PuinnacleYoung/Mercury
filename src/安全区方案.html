拾光·澈屿 · 全机型安全区方案

一份写给「做地图 / 做 UI / 摆装饰」的统一规范：哪里能放东西、哪里绝对不能放、画布该多大。 照着做，手机横屏、iPad、电脑三种屏幕看到的是同一个画面，只是整体缩放，不会跑位、不会挤、不会被 UI 压住。

世界画布 16:9 归一化坐标 0~1 contain 等比缩放 内容安全区 88% × 80%

1三层区域模型

任何一屏都分成三层。搞清楚这三层，往哪放东西就不会错：

L0
屏幕层 Screen
整块 window.innerWidth × innerHeight。 手机横屏约 855×400，iPad 横屏 1180×820，电脑 1920×1080。 这层的尺寸千变万化，不能拿它当设计基准。
L1 · 禁区
UI 禁区 UI-Exclusion
四角和边缘被 UI 控件占用的地方：顶部 HUD 条、左上状态、右上货币、 左下摇杆方块、左侧竖排按钮列。 这里绝对不能放房子、地块、触发区、可点击装饰 —— 会被压住点不到。
L2 · 可用
内容安全区 Safe-Content
中间这块干净的区域，才是你真正的可编辑区。 房子、地块、触发区、装饰、NPC 全部摆在这里。规范值：画布宽的 88% × 高的 80%。
🚫 最常见的翻车 把建筑摆在画布正下方或最左边 → 电脑上看着挺好 → 手机上被摇杆和按钮列完全盖住，玩家点不到。

2世界画布规范（核心）

2.1 固定 16:9 逻辑画布

不管玩家屏幕是什么比例，世界画布永远是 16:9（逻辑分辨率 1600×900）。你在编辑器里看到的比例，就是所有人看到的比例。

2.2 contain 等比缩放 + 居中留边

渲染时按 contain（短边贴合、等比不拉伸）缩放居中，多出来的部分留边（letterbox）。

电脑 16:9完美贴合，零留边（1920×1080 → 画布 1920×1080） iPad 4:3上下各留一点边（1180×820 → 画布 1180×664，上下各 78） 手机 21:9左右各留边（855×400 → 画布 711×400，左右各 72）— 正好被左侧按钮列和右侧留白吃掉
✅ 为什么留边是好事 手机横屏是 21:9（又宽又扁），如果强行拉伸到满屏，16:9 的设计会被横向拉扁 —— 圆变椭圆、格子变长方形。 改成 contain 后比例永远正确，而留出来的边刚好落在 UI 禁区上，视觉上完全看不出来。

2.3 一切坐标用归一化 0~1

地图节点、大厅装饰、建筑位置全部存 0~1 的小数（比如 x:0.5, y:0.3），渲染时乘以画布宽高。 这样换个屏幕尺寸，相对位置一像素都不错。这套机制项目里已经实现了，继续沿用即可。

🚫 绝对不要 用绝对像素存坐标（x:420, y:180）。那样手机上一打开，所有东西都堆在左上角。

6地图编辑器怎么用

6.1 画板尺寸

  • 画板固定 16:9，逻辑分辨率建议 1600×900（够清晰，也不至于太大）。
  • 编辑器里看到的画板比例 = 玩家看到的比例，所见即所得。
  • 节点位置存百分比，画板多大都不影响最终效果。

6.2 必开「安全框」叠加

编辑时叠加显示安全区边框（虚线橙色 + 绿色实心框）， 所有地块、触发区、装饰都必须放在绿框以内。这是防止"电脑上好看、手机上点不到"的唯一硬手段。

7一句话记住

🎯 三句话 ① 画布永远 16:9，坐标永远 0~1；
② 内容只放中间 88% × 80%，四周是 UI 的地盘；
③ 手机只是把电脑那套整体缩小，布局方向一个都不许改。
