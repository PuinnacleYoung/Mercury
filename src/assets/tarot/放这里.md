# 塔罗素材投放目录

把《塔罗编辑引擎.html》点「📦 导出 ZIP」得到的压缩包**解压后整个丢进这个目录**，保持下面的结构即可，游戏会自动识别：

```
assets/tarot/
├── meta.json          ← 必须（牌名/正逆位文案/哪些牌画好了）
├── back.webp          ← 牌背 500×800
├── back@2x.webp       ← 牌背 1000×1600
└── cards/
    ├── m0.webp  ~  m21.webp          ← 大阿卡纳 22 张
    ├── m0@2x.webp ~ m21@2x.webp
    ├── swands_ace.webp ~ spentacles_king.webp   ← 小阿卡纳 56 张
    └── ...@2x.webp
```

## 规则

- **没放任何东西**：游戏自动用 emoji 伪牌面，不会报错。
- **只画了几张**：画了的显示真图，没画的（meta.json 里 `done:false`）仍显示 emoji，可以边画边上线。
- **@2x**：只有 `devicePixelRatio > 1.3` 的高清屏才会加载，省流量。
- **WebP**：Chrome/Firefox/Safari 14+/Edge 都支持；极老设备会自动回落 emoji。

## ⚠️ 必须走 http(s)

游戏用 `fetch('assets/tarot/meta.json')` 读取，**`file://` 直接双击打开会被浏览器拦掉**（CORS），
这时候固定走 emoji 兜底。想看到真图请：

- 用本地服务器打开（`start-server.bat` → `http://localhost:8080`），或
- 部署到 GitHub Pages 后用网址访问。
