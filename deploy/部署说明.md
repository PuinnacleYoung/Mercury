## 二、买完之后，在控制台做一件事

**放行端口**：轻量控制台 → 实例详情 → 「防火墙」页签 → 添加规则，放行 **TCP 80** 和 **TCP 443**。
（这一步漏了就是"网页死活打不开"，没别的症状，最常见的翻车点。）

---

## 三、然后给臣这三样

1. **公网 IP**（控制台实例卡片上那一串数字，形如 `43.xxx.xxx.xxx`）
2. **登录用户名 + 密码**（用户名一般是 `root`，腾讯云 Ubuntu 镜像也可能是 `ubuntu`，看控制台提示）
3. 有没有**域名**（没有就说没有，先用 IP 访问，不影响联机）

给臣之后，臣 SSH 上去全自动装好，回来给陛下三条地址：导航首页 / 游戏入口 / 联机健康检查。

## 四、部署（服务器上只要跑 3 条命令）

### 方式 1：臣远程帮你装（推荐）
把 IP + root 密码给臣，臣用 SSH 全程装好并回报告。

### 方式 2：陛下自己动手

```bash
# ① 把部署包传上去（在你自己电脑上执行，不是服务器）
#    mercury-deploy.tar.gz 由臣打包好，放在 D:/projects/ 下
scp D:/projects/mercury-deploy.tar.gz root@你的IP:/root/

# ② 登录服务器
ssh root@你的IP

# ③ 解压 + 一键部署
cd /root && tar -xzf mercury-deploy.tar.gz && bash mercury/deploy/deploy.sh
```

脚本会自动：装 Node → 装 nginx → 拷代码到 `/opt/mercury` → 注册 systemd 守护联机服务 → 开防火墙 → 自检。

### ⚠️ 最容易踩的一个坑
**云控制台的「安全组 / 防火墙」要手动放行 80 和 443 端口**，不然网页死活打不开。
（8090 **不用**放行，它被 nginx 在内部反代了，更安全。）

## 五、怎么验证真的联机了

| 检查项 | 地址 | 期望 |
|---|---|---|
| 导航首页 | `http://IP/` | 出现三张入口卡片 |
| 游戏 | `http://IP/src/index.html` | 能进登录页 |
| 联机健康 | `http://IP:8090/health` | 返回 `{"ok":true,...}`（这条需要放行 8090，可临时开） |
| 真联机 | 两台设备（或手机 + 电脑）各开游戏进同一关卡 | 能看见彼此走动、能世界频道聊天 |

浏览器控制台（`F12`）里如果看到 `WebSocket connection to 'ws://...' failed`，说明 nginx 反代没生效，检查 `sudo nginx -t` 和 `systemctl status mercury`。

## 六、日常运维

| 想干啥 | 命令 |
|---|---|
| 看联机日志 | `tail -f /var/log/mercury.log` |
| 重启联机服务 | `systemctl restart mercury` |
| 停 / 开 | `systemctl stop mercury` / `systemctl start mercury` |
| 改后台管理口令 | 改 `/etc/systemd/system/mercury.service` 里的 `ADMIN_KEY`，然后 `systemctl daemon-reload && systemctl restart mercury` |
| 更新游戏代码 | 把新的 `src/` 传上去覆盖 `/opt/mercury/src/`，**不用重启**（nginx 直接服务静态文件） |
| 备份玩家数据 | `cp /opt/mercury/server/data.json /root/data-$(date +%F).json` |
| 改了 data.json | **必须** `systemctl restart mercury`，否则内存旧值会覆盖回去 |

### 数据在哪
所有玩家账号、好友、邮件、背包、货币都在 **`/opt/mercury/server/data.json`** 一个文件里。
建议每天备份一次（可以加个 crontab）。

## 七、已知风险（先说清楚，别到时候炸）

| 风险 | 说明 | 何时处理 |
|---|---|---|
| **账号可被冒用** | 现在只要知道别人的用户名就能顶替登录（服务器不校验密码） | 联机跑通后立刻加「登录口令」，臣已想好最小改法 |
| 后台口令默认值 | `ADMIN_KEY=change_me_please`，不改等于后台裸奔 | 部署完第一件事就改 |
| data.json 单点 | 服务器重装 / 误删就没了 | 加每日自动备份 |
| 明文 http | IP 直访时聊天内容不加密 | 上域名 + certbot 后自动解决 |

## 八、上线 https（有域名之后）

```bash
sudo certbot --nginx -d 你的域名          # 免费签证书，自动改配置
sudo cp /opt/mercury/deploy/nginx-https.conf /etc/nginx/conf.d/mercury.conf
sudo bash -c 'sed -i "s/你的域名/实际域名/g" /etc/nginx/conf.d/mercury.conf'
sudo nginx -t && sudo systemctl reload nginx
```

客户端已经写好了：https 页面自动连 `wss://域名/ws`，**代码一行都不用改**。
